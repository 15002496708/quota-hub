# 全国定额库共建 · 任务广场

把全国各省定额、标准、图集类官方 PDF 结构化为可验证、可复现、可审计的数据库——靠一个人做不完，所以我们共建。

本仓是**任务分发层**：悬赏任务以 Issue 形式发布与跟踪。**本仓不含源码、不含数据、不接收 PR。**

## 三层架构（源码与数据为什么不会泄露）

| 层 | 载体 | 谁可见 | 内容 |
|---|---|---|---|
| 任务层（你在这里） | 本公开仓 | 所有人 | 任务说明、状态标签、共建规则 |
| 交易层 | 工程人工具包站点 | 注册共建者 | 认领、交付包上传、门控验收、积分结算 |
| 核心层 | 私有仓 | 发起方 | 提取流水线源码、门控校验器、结构化数据库 |

贡献者全程接触的是：官方出版的原版 PDF（任何书店可买）+ 任务说明 + 交付规范。**接触不到提取脚本、校验规则与成品数据。**

## 参与流程（五步）

1. **选任务**：浏览本仓 [Issues](../../issues)，按 `status:开放` 标签筛选，看清交付单元与要求
2. **注册认领**：登录工程人工具包站点 → 定额库 → 共建悬赏 → 输入悬赏编号（QB-xxxxxx-xxx）认领，占位 14 天
3. **本地作业**：按《交付物规范》在你自己电脑上跑提取（大模型 API Key 自备，成本即你的入股）
4. **上传交付**：站点「我的共建 → 提交交付」直传 zip，服务端复算 sha256 留证
5. **验收结算**：我方门控体系机器验收（恒等式/指纹复现/交叉对账），全绿即核销，悬赏积分实时到账

## 交付物规范

```
deliver.zip
├── raw.json          忠实层产物（页面还原，禁时间戳，字节级可复现）
├── manifest.json     文件清单 + 各文件 sha256
└── fingerprint.json  基线指纹（页界签名 + 源 PDF sha256 前 12 位）
```

- 忠实层只读原则：忠实还原"页面上有什么"，不做造价判断；疑点进 issues 字段，禁静默修正
- 可复现原则：同一份 PDF 重跑产物字节一致（运行时时间戳是头号违禁品）
- 页码口径：物理页/印刷页双轨，页界签名随指纹提交

## 验收标准（门控，机器判，不扯皮）

- 基线指纹比对：忠实层字节级复现
- 恒等式回归：基价 = 人工费 + 材料费 + 机械费 + 综合费（±容差）
- 完整性：全库计量单位非空、章节归属合法
- **校核≠重做**：验收未过只给缺陷清单与取证，退回返修；返修后重新提交，不限次数

## 积分与权益

- 悬赏积分按任务标注发放（S=2000 / A=1000 / B=500 / C=200 为基准档）
- 核销后入悬赏池，可兑换站内权益（会员、图纸云盘空间、图集下载等）
- 重复核销不可能：积分流水幂等，一笔悬赏只结一次

## 保密约定

认领即视为同意：不转售/不公开交付物；不使用我方提供的任何规范文档从事竞争性产品；成品数据知识产权归发起方所有，贡献者享有积分权益与署名（可选）。
